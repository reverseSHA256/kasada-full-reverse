# Security Policy

## Supported versions

This repository is a historical research archive and is not a production-supported software project.

Because the project is archival and experimental, security fixes are handled opportunistically rather than through a strict versioned support policy.

## Reporting a vulnerability

If you discover a security issue in the repository or in a research prototype, please report it privately.

Use one of the following options:
- open a private GitHub Security Advisory if available for this repository
- open a private issue if the project owner has enabled that flow
- contact the repository maintainer directly through the GitHub profile associated with the project

Please include:
- the affected file or component
- the issue type
- reproduction steps or proof of concept
- the impact and risk level
- any suggested mitigation

## Responsible disclosure

Please do not disclose a vulnerability publicly until a fix or mitigation is available and the issue has been addressed.

## Scope

This policy applies to:
- Python scripts in the repository
- research tooling and local demos
- documentation examples that could be converted into active workloads

This policy does not apply to third-party historical artifacts or external services referenced only as research context.
